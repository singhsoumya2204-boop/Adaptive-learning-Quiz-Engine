# 🚀 Adaptive Learning Quiz Engine

## 📌 Project Overview

Adaptive Learning Quiz Engine is a full-stack web application designed to provide personalized quiz experiences using dynamic difficulty adjustment. The system analyzes user performance in real-time and adapts question difficulty to improve learning outcomes.

The project was developed as a CDAC PG-DAC major project using Spring Boot, React.js, MySQL, and RESTful APIs with layered architecture.

## ✨ Key Features

* 👤 User Authentication (Student / Admin)
* 🧠 Adaptive Difficulty Algorithm (Easy → Medium → Hard)
* 📊 Performance Tracking & Skill Evaluation
* 📝 Dynamic Quiz Flow
* 📈 Reports & Analytics Module
* 🔐 Role-Based Access Control
* 🤖 AI-Based MCQ Generation (Integration Concept)

---

## 🧩 System Architecture

The application follows a layered architecture:

* Controller Layer – Handles REST endpoints
* Service Layer – Business logic & adaptive flow
* Repository Layer – Database operations
* Entity Models – Question, User, QuizAttempt, SkillSnapshot

---

## 🔄 Adaptive Logic Workflow

1. Quiz starts at **Medium** difficulty.
2. Correct answers increase difficulty level.
3. Incorrect answers reduce difficulty.
